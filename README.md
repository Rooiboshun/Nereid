# 深海艇ネレイド

3人でオンラインで遊ぶ、声を出して叫び合う協力ゲームです。

▶ **[ブラウザでプレイ](https://rooiboshun.github.io/Nereid/)**

3人の乗員が、それぞれ**違う計器盤**の前に座ります。画面に出る指令は、**必ず他の誰かの盤の計器**を指しているので、自分では絶対に実行できません。読み上げて、相手に操作してもらうしかありません。

## 遊び方

1. 同じURLを3人で開く(アカウント登録もインストールも不要)
2. Discord などで通話をつなぐ ― **声が通っていることが前提のゲームです**
3. 全員が「配置につく」を押すと潜航開始

開いた順に**機関室 / 生命維持 / 操艦**へ自動で配席されます。合言葉を入れると部屋を分けられるので、別のグループと同時に遊べます。

1人のときは「単独訓練」で3局とも自分で操作できます。

## ルール

| 出来事 | 影響 |
|---|---|
| 指令を時間内に処理 | 潜航が進む(深度 +35〜85 m) |
| 時間切れ | 船殻強度 −18% |
| 誰も頼んでいない計器を操作 | 船殻強度 −4% |

船殻強度が 0 になると圧壊、**深度 2,000 m の海溝底に到達すればクリア**です。深く潜るほど制限時間が縮み(16秒→6.5秒)、600 m からは制限時間が6割の「緊急指令」が混ざります。

## 計器

紛らわしい名前と単位をわざと隣り合わせています。慌てると「推力偏向」と「トリム角」、「主機出力」と「ソナー利得」を取り違えます。

| 局 | 計器 |
|---|---|
| 機関室 | 主機出力 / 冷却水弁 / 蓄電池 / 非常発電 / 推力偏向 / 過負荷遮断 |
| 生命維持 | 酸素分圧 / 炭酸吸収 / 艙内与圧 / 循環ファン / 予備空気 / 警報消音 |
| 操艦 | 主バラスト / トリム角 / ソナー利得 / 投光器 / マニピュレータ / 緊急吹鳴 |

## 技術メモ

依存ライブラリは Supabase JS のみ、ビルド不要の HTML1ファイル構成です。

- 同期は **Supabase Realtime の Broadcast + Presence**。データベーステーブルを使わないため、既存プロジェクトに相乗りできます
- 最初に入室した人が**艇長**として進行を持ち、他の2人は操作を送って状態を受け取ります。艇長が抜けると次の人が引き継ぎます
- 制限時間は絶対時刻で保持しています。`requestAnimationFrame` は裏タブで停止するため、進行は `setInterval` で回しています
- 効果音は WebAudio による合成音(音声ファイル不要)

## 開発

`index.html` をブラウザで直接開いても動きます。ローカルサーバーで確認する場合:

```sh
node serve.js
```
